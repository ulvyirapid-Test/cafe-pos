- **លក់ & តុ** — តុ 12, ខ្ចប់ច្រើនក្រុម (#1, #2...), Ticket Barista, ចំណាំភេសជ្ជៈ, Split bill, ផ្ទេរ/បញ្ចូលតុ

- **សមាជិក & ពិន្ទុ** — ភ្ជាប់តាមលេខទូរស័ព្ទ, ទទួល/ប្រើពិន្ទុ
- **ស្តុក** — កាត់ស្តុកតាមរូបមន្ត, ទិញចូល (ថ្លៃដើមមធ្យម), រាប់ស្តុក, Alert ស្តុកទាប
- **វេន** — X/Z-Report, ដកប្រាក់ពីថត, Variance
- **របាយការណ៍** — ជ្រើសថ្ងៃ, ចំណូល, COGS, ប្រាក់ចំណេញ, Margin, ម៉ោងលក់, Export CSV
- **ទិន្នន័យ** — IndexedDB (ផ្ទុកបានច្រើន GB), Archive តាមខែ, Backup អ៊ិនគ្រីប, Google Sheet Sync, Offline
- **Telegram** — បិទវេន, ស្តុកទាប, Void, សុវត្ថិភាព
- **សុវត្ថិភាព & សិទ្ធិ** — PIN អ៊ិនគ្រីប, ចាក់សោពេលបញ្ចូលខុស, Audit Log, កំណត់សិទ្ធិតាមតួនាទី/ម្នាក់ៗ
