# ☕ Angkor Artisan Café — POS & Management

ប្រព័ន្ធលក់ និងគ្រប់គ្រងហាងកាហ្វេ (HTML តែមួយ ដំណើរការក្នុង browser គ្មាន server)។

## មុខងារ
- **POS & តុ** — តុ 12 + Takeaway, កែសម្រួលភេសជ្ជៈ (ទំហំ/ស្ករ/ទឹកកក/Topping), ផ្ទេរ/បញ្ចូលតុ, បញ្ចុះតម្លៃ, បង់ប្រាក់ Cash / KHQR / Card, វិក្កយបត្រ 80mm
- **ស្តុកវត្ថុធាតុដើម** — កាត់ស្តុកស្វ័យប្រវត្តិតាមរូបមន្ត, តាមដានស្តុកចូល/ប្រើប្រាស់, Alert ស្តុកទាប
- **វិភាគការលក់** — ប្រចាំថ្ងៃ / ៧ ថ្ងៃ / ខែនេះ
- **វេនការងារ** — X-Report, បិទវេន Z-Report, ផ្ទៀងផ្ទាត់ថតប្រាក់ (Variance), ប្រវត្តិវេន
- **Menu & រូបមន្ត** — បន្ថែម/កែ/លុប មុខម្ហូប និងរូបមន្ត, Upload KHQR របស់ហាង, Backup / Restore

## ប្រើប្រាស់
បើក `index.html` ក្នុង browser ឬចូលតាម link GitHub Pages។

## ចំណាំសំខាន់
- ទិន្នន័យរក្សាទុកក្នុង **browser (localStorage)** នៃម៉ាស៊ីននីមួយៗ។ សូម **Export Backup** ជាប្រចាំ (ផ្ទាំង 5)។
- KHQR ប្រើរូប QR ពិតរបស់ហាងដែលបាន upload (static QR)។ បុគ្គលិកត្រូវពិនិត្យសារជូនដំណឹងពីធនាគារ មុនបញ្ជាក់ការបង់ប្រាក់។
- អត្រាប្តូរប្រាក់កំណត់ $1 = 4,100 ៛ (កែក្នុង `KHR_RATE`)។
